# New repo checklist

1. Pick a category and its prefix: `data-` · `auto-` · `web-` · `mobile-` · `soft-` · `client-`
2. Name it in lowercase with dashes, e.g. `web-booking-portal`
3. Create it in one command:
   `gh repo create atifmahmoodai/web-booking-portal --public --description "..." --add-readme && gh repo edit atifmahmoodai/web-booking-portal --add-topic web-app`
4. Add a line under the right section in your profile README (`atifmahmoodai/atifmahmoodai`)
5. Client work with confidential code: use `--private`
